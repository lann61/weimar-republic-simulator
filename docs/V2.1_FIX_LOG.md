  - 新增 `src/simulation/events/adapter.ts`：按当前政权改写角色术语（总统→皇帝、国会→帝国议会、总理→帝国总理）；按当前政府改写历史政府/内阁名称（库诺政府→当前政府）；按当前元首改写“总统X”。
  - `EventModal.tsx`：所有事件的标题、背景、选项文案在渲染时经过适配器。
  - `engine.ts`：`applyChoice` 使用 `adaptChoiceEffects`，玩家显著偏离史实后不再安装与当前政局不符的史实内阁或总理。
- **测试：** `WMR-029 帝制路径的事件叙述按当前政权改写`、`WMR-029 偏离史实后不安装史实内阁`、`WMR-029 全部 124 个事件在帝制状态下不残留共和国措辞`、`WMR-029 偏离后的共和国状态不残留其他历史总理政府`。
- **结果：** ✅ 通过（91/91）。全部 124 个事件在帝制状态下无“总统/国会”残留；共和国偏离后无其他历史总理政府残留。

### WMR-030｜偏离史实后国会永远不产生（严重，任务书外新增） — ✅ 完成

- **根因：** WMR-028 用 anchor 门控历史选举后，玩家一旦显著偏离，历史选举日程被关闭，但没有任何替代选举机制；1919 制宪选举也被跳过，导致 `parliamentSeatsTotal` 为 0、各党席位为 0、政府退化为看守政府，且此后永远不选举。
- **修复（`step.ts`）：**
  - **制宪选举**：`state.elections.length === 0` 且日期 ≥ 1919-01 时，无论锚定强弱都举行国民议会选举；锚定强用史实数据，偏离用模型计算。
  - **定期选举**：偏离史实（anchor ≤ 0.55）后，距上次选举满 48 个月即举行模型选举，避免历史日程关闭后永远不选举。
  - 选举后由 `runElection` 调用 `formGovernment` 组阁，政府不再停留在看守状态。
- **测试：** `WMR-030 偏离史实后仍举行制宪选举并产生国会与政府`（君主制偏离路径）；并手动验证共和国低锚定路径：1919 选举、423 席、Wels 联合政府。
- **结果：** ✅ 通过（92/92）。
