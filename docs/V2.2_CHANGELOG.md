# V2.2：选择、历史连续性与状态一致性

2026-11-01。本次修改对应游戏检查报告的六个方面。当前构建与数据版本均为 2.2.0。

## 1. 事件结算与日期

- 取消每月三次决策上限，所有已触发事件逐一展示；只有玩家主动点击“暂不干预”才委托处理。系统处理单独标记，不计入玩家决策次数。
- 事件、选举、政府任命及延迟后果共用日级游标；每次选择后重新检查队列。随机未命中只记录评估月份，不写入已发生事件，可在下一月份重新评估。
- 修正共产党议席事件与授权法的前置日期；授权法、各邦接管等不再自动处理或遗漏。
- 推迟选举会调整实际选举日程和相关三月事件；开局不再提前载入起始月尚未举行的选举结果。
- 月度模拟统一推进到月初；月内按日执行，月末完成快照、挑战结算；最终停止于 1934-08-31。

## 2. 每个选择的持续后果

当前共有 127 个事件、381 个选项。

- 所有选项均保留 `choice_事件ID_选项ID` 结果标记、实际决策日期、即时指标变化、后续说明和可识别的前因。
- 每个选项在三个月后有一笔可追溯的落实结算。默认落实量取直接影响的 12%，每项限于 ±1.5，最多四项；这是模型参数，不是史料数据。事件可另设具体到期后果。
- 决策对社会、制度、外交的直接影响在十二个月内留下小幅持续反馈（最多三项，每月限于 ±0.12），并进入月度耦合模型。
- 关键制度结果使用独立状态：条约是否接受、被动抵抗是否持续、保险融资妥协、是否同意总统继任安排、公民权利是否暂停、授权法是否通过、司法是否清洗、工会是否禁止、一党制、职权合并、军队个人效忠。
- 保险融资妥协可阻止预定倒阁；反对授权法可阻断后续制度拆除；结束被动抵抗和谈判复工有实际落实期限。
- 新增三个月过渡安排复审、通用政府信任危机和反事实总统继任程序。偏离后的内阁危机使用当前政府语境，并由模型重新组阁，不再靠删除史实内阁事件规避矛盾。
- 明确的人物任命不会因为偏离度较高而被删除；系统历史日程受到玩家已作出的人事与议会安排约束。

持续结果通过相关因果通道传导，不强迫每个选择立即修改所有指标，也不保证每个选择单独改变最终结局。

## 3. 政党、法令与最终状态

- 第48条政策、事件和总统内阁共用法令结算规则：次数、有效期限、记录与制度影响同步更新。
- 政党禁令及共产党议席取消会清除有效席位、更新合法性、执政支持、议会总席位和多数门槛；历史选举档案保持原记录。
- 一党制、权利暂停、司法清洗、授权法和工会禁令持续约束模型；普通月度回归不能将这些制度自动撤销。
- 席位过半不再直接终止模拟。最终结局依据实际制度结果，区分君主立宪、代表会和威权秩序；独裁巩固要求一党制、职权合并和个人效忠同时成立。
- 最终状态冻结，不能再实施政策、处理选择或推进时间；自动展示最终报告。

## 4. 选举、经济与挑战

- 零偏离的历史观察模式展示原始史实选举，明确不计模型贡献；干预模式真实计算加权份额和席位，不再通过 60% 阈值直接覆盖玩家影响。
- 模型选举公平性受到本局权利限制影响。
- 取消按“希特勒是否任总理”直接增产、降低失业的特殊加成；就业与产出由需求、信贷、国际周期和已实施政策共同决定。
- 失业率对产出缺口的传导改为线性，减少旧模型在多条路径下共同收敛到极高失业的情况。经济数值仍属研究模型，需要持续校准。
- 相反方向的福利、税收、财政及贸易政策互相替换；重复点击同一生效政策不会叠加。
- 财政政策成本与月度赤字安排进入财政支出目标，不再先直接修改赤字、随后无痕覆盖。
- 挑战说明中的主要限制已结构化，按各目标自己的截止日结算；截止日内选择可计入，跨过截止日后不能补做。

## 5. 报告、解释、存档与布局

- 展示本局全部选择与系统处理记录，使用事件名称，可跳转档案查看前因与后续。
- 指标解释优先显示实际记录的增减；预设机制说明不再展示为实际贡献百分比。
- 失业、暴力等负面指标的增量正确显示为负向颜色；货币、税收等中性指标不暗示固定好坏。
- 皇帝、代表会主席等使用实际头衔；进行中报告不再宣称已经结束。
- 增加 JSON 导入入口、结构验证、旧版本结果标记和制度约束迁移。失败导入不会替换当前游戏；旧档缺失的历史因果贡献不会被补造。
- 结束后的存档载入直接显示报告；支持导出再导入。
- 适配 688px 与 390px 窗口：顶部操作换行、主内容单列、手机横向导航和滚动事件卡。

## 6. 验证方式

```sh
npm test -- --no-cache
npm run validate:data
npm run audit:branches
npm run build
npm run test:e2e
npm run test:flows
```

`tests/branching.test.ts` 覆盖跨事件结果、时间顺序、议席/法令一致性、制度约束、相反政策、挑战截止日、存档与结束冻结。

`docs/V2.2_BRANCH_AUDIT.json` 记录九个场景、三种固定策略、三个种子的完整模拟，以及从实际可达状态替换选项后继续到结局的分支检查。具体覆盖与未触发事件见 JSON 的 `summary`，不将独立选项应用检查冒充全组合穷举。

`e2e/flows.mjs` 从开始界面通过真实按钮走完历史流程，检查授权法与各邦接管可选、最终报告、保存/导出/导入、结束冻结、窄屏及君主制事件语境。截图保存在 `shots/v2.2/`。

端到端脚本优先使用 Playwright Chromium；本机未安装对应 Chromium 时使用已安装的 Edge，不自动下载浏览器。
