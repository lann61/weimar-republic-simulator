## 4. 选举数据使用方式变更（非数据改写）

- **未修改** `src/data/elections.ts` 中的任何历史票数、得票率、席位或日期。
- 历史模式（锚定 `w > 0.6`）现在**直接采用**史料：
  - `date` 使用真实选举日（如 1932-07-31、1932-11-06、1933-03-05）。
  - `totalSeats` 使用史料总席位（608 / 584 / 647）。
  - 各党 `votes` / `vote_share` / `seats` 取自 `elections.ts`。
  - `other_seats` / `other_vote_share` 保留为 `otherSeats` / `otherVoteShare`。
- 反事实/自由模式仍由模型计算，并标记为 `simulated`。

## 5. 已知数据质量问题（未在本次修改）

- 110 条人物党籍记录的 `from` 默认等于出生日期（WMR-011），已由 `validate:data` 以警告形式列出，未伪造真实入党日期。
- 1919 年国民议会 421/423 席、SPD 163/165 席的口径差异保留在 `elections.ts` 的 `notes` 中，未静默拼接。
