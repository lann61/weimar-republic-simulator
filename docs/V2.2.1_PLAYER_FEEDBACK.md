# V2.2.1：政府、选举与选择的持续影响

对应玩家反馈的三项修正。版本 2.2.1，数据格式兼容 2.2.0。

## 政府事件使用本局人物

问题来自两个条件不一致：展示层只根据锚定阈值决定是否改写文本，实际政府却可能早已由模型产生；原有替换也未覆盖独立出现的人名。

现在政府危机、内阁政策争议使用当前政府首脑、国家元首和实际支持关系。背景、选项和参与者同步改写。历史档案继续保留原事件供对照，不冒充本局事实。模型选举卡展示本局真实席位、组阁结果与首脑，避免仍宣称史实政党胜出。

## 选举与组阁

- 干预、自由与挑战模式每次选举均按新席位重新组阁，高锚定不再跳过组阁、强制保留历史内阁。
- 只在零偏离的历史观察模式保留历史任命日程。玩家已建立的政府不会在干预局被日历直接覆盖。
- 相同党派与多数联盟可以让现任续任，这不等于选举没有作用；政府任期、席位、支持关系及组阁记录仍重新结算。
- 取消按任期长短随机更换首脑。失去有效多数或出现明确的信任危机时，先弹出事件，由玩家选择协商、重组或重新选举。
- 政府危机可再次出现，但有三个月间隔；延迟后果记录使用唯一标识，档案显示最新一次处理。
- 总览显示最近选举的组阁结果。重新组阁时清理旧党派的执政与容忍标记。

## 决策影响不再只是一笔短期增减

此前十二个月记忆影响幅度较小，基础模型又将变量拉回固定目标，部分效果很快消散。

新增需求、外交合作、社会协调、制度监督四个持续政策方向（模型指数 −20 至 20）。方向由实际选择的经济、外交、社会与制度效果累积，进入以下月度目标：

- 外交合作影响双边关系与资本信心目标，再经信贷与外资进入经济模型。
- 需求取向改变产出目标，就业、消费与财政继而反馈。
- 社会协调影响极化与暴力的目标值；制度监督影响议会权威。
- 总览展示累计方向与最近决策的后续说明。旧存档缺少方向时，从已记录选择重建，不重新执行即时效果。

这些系数是游戏模型参数，不是历史统计，也不意味着每一个选择必然改变最终结局。

## 同种子对照

种子 42、历史干预模式、同一洛迦诺事件，只更换该次选择，之后十二个月均采用相同默认选择策略。结果详见 `V2.2.1_CHOICE_COMPARISON.json`。
