## 部分通过项的具体缺口

### #12 内阁名单完整性

已录入 22 届内阁（1918-11 至 1934-08），每届覆盖总理、副总理与主要部长（外交、内政、财政、
经济、劳工、司法、国防、农业、交通、教育、无任所）。缺口：

- 部分届次的次要部长（如殖民、被占领区、卫生、重建）未录入；
- 部分兼任关系未逐一列出；
- 部分部长的精确起止日只精确到月。

界面与数据 `notes` 中已注明"待档案逐项核验，未录入者不虚构补全"。

### #14 人物关系网络

当前实现为**结构化关联**而非图形化关系图：

- 人物—政党：`party_memberships` 分段
- 人物—政府：由 `governments.members` 合并为 `offices`
- 人物—事件：事件 `participants` 反向索引

方案 §26.12 要求的关系图（含方向、类型、证据、时间范围）尚未实现可视化组件。
`types.ts` 中已预留 `relationships` 字段结构，但数据未填充。

## 与方案的偏离（主动说明）

1. **数据以 TypeScript 模块而非 JSON 文件存放**。方案 §15.2 建议 `data/*.json`。
   改为 TS 模块以获得编译期类型检查与测试期校验；数据内容与结构完全对应，
   不影响"数据驱动"与"可扩充"要求。

2. **未实现议会逐项法案投票表**。方案 §25.8 要求记录议案、赞成/反对/弃权票与各党倾向。
   本项目只记录可证实的史实结果与本局发生的制度行为（第48条、政府更迭、选举），
   并在界面说明"多数历史国会投票的逐名记录无法完整取得，不伪造逐名投票"。

3. **经济模型为简化宏观动力学**，不是计量模型。系数为研究型参数，校准目标为
   选举结构与衰退的定性走势，而非精确复现 GDP 或失业序列（见 `SIMULATION_MODEL.md` §8）。

4. **历史地图为示意图**。34 个选区以矩形块近似地理分布，标注 `simulation_derived`，
   不使用受版权保护的边界数据。
