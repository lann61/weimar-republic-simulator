## 一、创作声明

1. **独立创作**：本项目由 Eumenes 独立构思、设计与开发，为个人创作的政治文明演化模拟器，非任何机构委托或职务作品。

2. **创作目的**：以 1918/1919—1934 年魏玛共和国为对象，通过可交互的历史情境，呈现民主制度在选举、组阁、经济危机、街头暴力与精英交易中逐步瓦解的过程，用于历史教育与政治学兴趣学习。

3. **原创内容**：以下内容为作者原创：
   - 全部源代码、模拟引擎、选举与组阁算法、经济与社会模型；
   - 界面设计、交互流程与视觉风格；
   - 事件文本、选项描述、结局判定与报告文本；
   - 数据结构、参数设定与项目文档。

4. **史料使用**：历史人物姓名、职务、党籍、选举结果、内阁名单、条约节点等事实性信息，整理自德国联邦议院、德国历史博物馆 LeMO、德国联邦档案馆、GHDI、USHMM、Konrad-Adenauer-Stiftung 及德国议会人物数据库等公开来源，逐条列于 `docs/HISTORICAL_SOURCES.md`，并在数据字段与界面中标注。本项目不复制上述来源的受版权保护文本或图像。

5. **模拟性质**：模型中的支持度、制度指数、经济变量、推演选举与推演内阁均为研究型估算，**不是史料统计值，也不构成对历史人物或历史事件的价值判断**。模拟结果仅用于教育与研究，不代表作者的政治立场。

6. **无授权肖像**：本项目不打包任何历史人物肖像、海报或档案扫描件；人物卡使用中性剪影并注明「无授权肖像」。
